# THE GLYPH-LAYER INTERNET PROTOCOL (GLIP v1.0)
### Een Nieuwe Semantische Internet- en Cryptografielaag Bovenop het Bestaande Web
### Defensive Publication · Humanity Heritage License π

Dit project bevat de officiële priordepositie van **GLIP v1.0** — een nieuwe 
laag voor adressering, routing, identiteit en cryptografie die werkt *bovenop* 
het bestaande internet, zonder dat bestaande netwerken, browsers of protocollen 
aangepast hoeven te worden.

GLIP maakt gebruik van:
- glyphs (unicode-weergaven van Ω-vectoren)
- energetische richting en curvature
- semantische routing i.p.v. klassieke URL’s
- veldgebaseerde authenticatie (coherentie)
- een niet-brute-forcebare cryptografie (GlyphCrypto)

Het protocol functioneert als overlay boven HTTP/HTTPS en kan direct worden 
gebruikt op elke server. De semantiek zit in het GLIP-systeem zelf, niet in 
het internet.

### Kernidee in één zin
GLIP introduceert een internetlaag waarbij adressen, API-calls en identiteit 
niet langer tekstgebaseerd zijn, maar worden gegenereerd uit Ω-vectoren 
(geometrische/energetische toestanden), gerepresenteerd als glyphs.
